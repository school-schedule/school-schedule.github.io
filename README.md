# המערכת שלי — моё расписание

Веб-приложение, которое показывает каждому ученику параллели **его личное расписание** вместе с отменами уроков, сменой кабинета, контрольными и экзаменами.

## Какую проблему решает

В нашей школе два приложения, и у каждого половина того, что нужно:

| | משוב | שחף | **המערכת שלי** |
|---|---|---|---|
| Личное расписание ученика | ✅ | ❌ (общее на всю параллель) | ✅ |
| Отмены, смена кабинета, контрольные | ❌ | ✅ | ✅ |

Приложение объединяет лучшее из двух: ученик один раз выбирает свои группы и дальше видит только свои уроки, уже с изменениями на сегодня.

## Возможности

**Для ученика**
- Без регистрации: один раз выбираешь свои группы, и выбор запоминается на телефоне.
- Сразу открывается расписание на сегодня. Дни можно листать стрелками или свайпом.
- Отменённый урок зачёркнут красным, смена кабинета выделена жёлтым маркером, контрольная и экзамен отмечены своим цветом.
- Свободные уроки видны как отдельные строки, поэтому понятно, где «окно».
- Три языка: иврит (справа налево), английский и русский.
- Удобно на телефоне: крупные кнопки, тёмная тема.

**Для редактора**
- Вход по коду.
- Недельное расписание: для каждого класса и группы видны все уроки дня, и свободный урок можно заполнить одним нажатием «+».
- Изменения по датам: отмена, новый кабинет, контрольная или экзамен на конкретный день.
- Настройки: классы, предметы, группы, время звонков, код редактора.
- Изменения видят все ученики сразу после публикации.

## Как устроено

- **Один файл `index.html`**: HTML, CSS и JavaScript без сборки и без фреймворков.
- **Данные** (классы, группы, уроки, изменения) хранятся внутри страницы в формате JSON. Когда редактор нажимает «Опубликовать», приложение пересобирает себя с новыми данными и выпускает новую версию.
- **Выбор ученика** хранится только в его браузере (`localStorage`). Приложение не собирает личные данные и не подключается к системам Министерства образования.

### Модель данных

```
periods   — время уроков (номер → начало и конец)
subjects  — предметы; предмет с группами — это «выбор» (математика, английский, блоки мегамот)
groups    — группы внутри выбора (например, «5 יח״ל, учитель такой-то»)
classes   — классы (буква параллели + номер, например י׳2)
lessons   — урок: день, номер урока, предмет, учитель, кабинет и для кого (класс или группа)
changes   — изменение: дата, урок, тип (отмена, кабинет, контрольная, экзамен), заметка
```

Личное расписание = уроки класса ученика + уроки всех выбранных им групп + изменения на эту дату.

Два типа выбора:
- **одна группа**: математика, английский, физкультура;
- **несколько групп**: блоки мегамот. Там есть вариант «свободный урок», который нельзя совместить с другими.

Некоторые решения:
- Свободные уроки не хранятся в данных, а вычисляются: номер урока без занятия = свободный урок.
- Время уроков хранится отдельно от уроков, поэтому новое расписание звонков меняется в одном месте.
- Выбор ученика связан с группами через id, поэтому переименование группы не сбрасывает выбор.
- Код редактора хранится как хеш SHA-256, а не открытым текстом.

## Как запустить

Скачай `index.html` и открой его в браузере: расписание и выбор групп будут работать.

Публикация изменений из редактора сейчас работает только в опубликованной версии на Claude. Для своего хостинга эту часть нужно перевести на базу данных (см. планы).

## Ограничения первой версии

- Одна параллель (сейчас класс י׳2).
- Расписание вносится вручную по данным из שחף.
- Код редактора защищает слабо, потому что лежит в самой странице. Настоящая защита — это право на публикацию.
