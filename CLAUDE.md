# CLAUDE.md

## Что это

**Skedy** (от *schedule*; раньше «המערכת שלי») — веб-приложение (PWA) с личным расписанием ученика параллели י׳ (10-е классы). Ученик один раз выбирает класс и свои группы (математика, английский, мегамот и т. д.) и дальше видит только свои уроки на день, уже с изменениями: отмена, другой кабинет, контрольная, экзамен. Редакторы по коду входят в режим редактирования и публикуют изменения для всех.

- Сайт: GitHub Pages, `https://school-schedule.github.io/`. Деплой автоматический: всё, что попало в ветку по умолчанию, сразу видят ученики.
- Сервер данных: Cloudflare Worker (адрес в `config.js`). Его код — в `worker/` (`src/worker.js`, `wrangler.toml`), скачан из Cloudflare. Это копия: GitHub его **не** деплоит, работающий Worker меняется только через `wrangler deploy`. Секреты (`EDITOR_CODE`) — только в Cloudflare Secrets, никогда в коде.
- Без сборки, без фреймворков, без npm: чистые HTML + CSS + JS (ES5-стиль: `var`, `function`).
- Три языка интерфейса: иврит (по умолчанию, RTL), английский, русский.

## Файлы

| Файл | За что отвечает |
|---|---|
| `index.html` | **Всё приложение** в одном файле: `<head>`, CSS, данные и JS. ~1090 строк, но некоторые строки огромные (см. ниже). |
| `config.js` | Одна строка: `window.SCHEDULE_API` — адрес сервера на Cloudflare. Без него редактор не может войти и публиковать: другого режима нет. |
| `sw.js` | Service worker: push-уведомления (по нажатию открывает приложение) и работа без интернета: файлы сайта берёт из сети, без сети (или если сеть молчит 4 с) — из кэша `app-v3`; шрифты Google — из кэша. Запросы к Worker не кэширует. При изменении списка файлов меняй `CACHE`. |
| `manifest.webmanifest` | Манифест PWA (название, цвета `#171717`, иконки, RTL). |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Иконки приложения. |
| `README.md` | Короткое описание проекта для людей (на английском). |
| `worker/` | Код Cloudflare Worker и `wrangler.toml` без секретов. |
| `.gitignore` | Исключает `.DS_Store`, `.dev.vars`, `.wrangler`, `node_modules`. |
| `.claude/settings.json`, `.claude/hooks/check-code.mjs` | Хук проверки кода (см. «Проверка»). |

### Устройство `index.html`

| Строки (примерно) | Что там |
|---|---|
| 1–18 | `<head>`: мета-теги, иконки (base64), `config.js`, манифест, шрифт Rubik. |
| 19–315 | `<style id="app-css">`: базовые стили в духе iOS, затем палитры `data-look="p1…p4"`. Активна **p2** («лайм»: фон `#171717`, акцент `#C6FF00`, шрифт Rubik) — её правила идут последними и перекрывают базовые. |
| **319** | `<script type="application/json" id="app-state">` — **все данные расписания одной строкой ~120 КБ**. Встроенная копия для первого показа: приложение сразу подгружает свежие данные с `API/data`. |
| 320–1089 | `<script id="app-js">` — весь код в одной IIFE. |

Разделы JS (ищи по комментариям `/* ---------- … ---------- */`):
- **storage helpers** — `sGet/sSet/sDel` (обёртки над `localStorage`/`sessionStorage` в try/catch), `esc()` для экранирования HTML.
- **texts** — словарь `T` с ключами `he`/`en`/`ru`; `t('ключ')` возвращает текст, `nm(obj)` — название объекта на текущем языке.
- **state** — `prefs` (выбор ученика), `ui` (текущий экран и состояние), `draft`/`dirty` (черновик редактора); функции дат (`iso`, `schoolDay`, `stepDay`), подбор групп (`groupsFor`, `subjectsFor`, `groupFits`; у предмета с `open: true` — сейчас английский `cat_eng`, ставит миграция Worker — показываются все группы, если у класса вообще есть этот предмет; галочка в редакторе предмета), `migratePrefs()`, `studentLessons(date)`.
- **streak** — `bumpStreak` (дни подряд в `localStorage["sched.streak"]` = `{last, n, best}`; пятница и суббота не обрывают), `streakPill` — огонёк справа вверху вместо языков; язык — во вкладке «Ещё» (на экранах выбора класса и входа — в шапке).
- **achievements / logo of the day** — `ACH` (14 значков, `localStorage["sched.ach"]`), `unlock(id)` (тост и конфетти), `achCheck()` (по стрику, друзьям, отменам, времени, установке), `renderAch()` во вкладке «Ещё». `OCCASIONS` — праздники учебного года 2026–2027 (даты правятся там), иначе первая неделя сезона `SEASONS` (1–7 сентября, декабря, марта, июня), в остальные дни логотип без значка; `logoHtml()` — значок на логотипе, нажатие — поздравление.
- **monthly recap** — итоги прошлого месяца как истории: `recapData(ym)` считает в телефоне (уроки, часы, отмены, контрольные, кабинет и предмет месяца, дни с приложением из `localStorage["sched.opens"]`), `renderRecap`; плашка на экране дня в первые 7 дней месяца (пока не открыли, `sched.recapSeen`), кнопка во вкладке «Ещё».
- **student screens** — `renderWelcome` (первый запуск, пока класс не выбирали: иконка, три пункта, «Выбрать класс», язык, установка, вход редактора; `firstScreen()` выбирает стартовый экран), `renderSetup` (выбор класса и групп), `renderDay` (день: текущий урок `is-now`, следующий `is-next` по времени из `periods`; выходные и события из `STATE.events`), `lessonCard`, `footer`, `renderInstall` (инструкция установки PWA), `renderTests` (ближайшие контрольные на 3 недели, `upcomingTests`), `renderMore` (вкладка «Ещё»: уведомления, сообщение об ошибке, установка, смена класса, вход редактора — это `footer(true)`), `syncNav` (нижняя панель вкладок `day`/`tests`/`pals`/`more`; живёт вне `#root`), `renderPals` (вкладка «Друзья»: свой код `palSync` → POST `/pal`, друзья в `localStorage["sched.pals"]` (имя только локально), `renderCompare` — две колонки «я | друг», `renderCrowd` — «кто сейчас свободен» по GET `/crowd`, `renderTeacher` — найти учителя; ссылка `#pal=КОД` открывает добавление друга; взаимность: после добавления POST `/pal/link`, а у второго при открытии POST `/pal/inbox` добавляет первого как «Друг КОД», переименование ✏️), `lessonsFor(date, classId, groupIds)` — уроки для любого выбора, `renderChat`/`chatSend`/`chatLoad` (чат поддержки: ключ переписки `localStorage["sched.chat"]`, POST `/chat` и `/chat/get`; открытый чат опрашивается раз в 8 с, непрочитанные — кружок на вкладке «Ещё»).
- **editor** — `renderLogin`, `renderEditor` и вкладки `edChanges` (изменения по датам), `edWeek` (недельное расписание), `edSetup` (классы и группы), `edSettings` (время звонков, код, резервные копии), `edStats` (сколько устройств пользуются приложением: сегодня, 7 и 30 дней, всего, по классам; GET `/stats` с `X-Editor-Code`), `edReports` (вкладка «Сообщения»: переписки чата — GET `/chats`, POST `/chats/open|reply|delete`, опрос раз в 8 с; ниже старые сообщения `edOldReports` — GET `/notes`).
- **sheets** — нижние листы редактирования: `renderSheet`, `sheetSave`, `sheetDel`.
- **publish** — `loadRemote` (GET `/data`), `publishRemote` (POST `/data` с заголовком `X-Editor-Code` и `base: updatedAt`; 409 = кто-то опубликовал раньше), резервные копии, push (`/vapid`, `/subscribe`, `/unsubscribe`), анонимный счётчик `pingStats` (POST `/hi` = `/ping` раз в день и при смене выбора: случайный id устройства из `localStorage["sched.device"]`, класс и id групп; отметка — в `sched.ping`; ошибки молча игнорируются). Адреса для сайта нейтральные (`/hi`, `/devices`, `/note`, `/notes`, `/pal`, `/crowd`) — блокировщики рекламы режут `stats`/`ping`/`report`. Код редактора в заголовке — `encodeURIComponent`. Последние данные с сервера хранятся в `localStorage["sched.data"]` и при старте заменяют встроенные, если новее (работа без интернета).
- **render** — `render()` собирает весь HTML строкой и кладёт в `#root.innerHTML`. Обработка кликов — делегирование по атрибуту `data-act="…"` (большой `switch`), плюс свайп для смены дня.
- **start** — выбор стартового экрана, аналитика Cloudflare (только на `school-schedule.github.io`), регистрация `sw.js`.

## Модель данных (`app-state`)

```
periods  [{n, start, end}]                         время уроков, n = номер урока
subjects [{id, he, en, ru, multi?, open?}]         предметы; с группами = «выбор» (cat_math, cat_eng, cat_b …); open — группы не делятся по классам
groups   [{id, subjectId, he, en, ru, teacher?, classId?, exceptClasses?}]
classes  [{id, he, en, ru, letter, num}]           например י׳2: letter "י", num 2
lessons  [{id, day 0–4 (вс–чт), period, subjectId, aud:{type:"class"|"group", id}, teacher, room}]
changes  [{id, date "YYYY-MM-DD", lessonId, type:"cancel"|"room"|"test"|"exam", room?, note?}]
events   [{date, text, off, cls?, from?, to?, room?, teacher?}]  события из שחף («אירועים»), пишет только Worker; off = учёбы нет; cls — если не для всех классов; from/to — уроки; teacher — событие одной группы (видят ученики этого учителя)
updatedAt, version, gradeName, migrations
```

- Личное расписание = уроки класса ученика + уроки выбранных им групп + изменения на дату.
- Свободные уроки **не хранятся** — это номера уроков без занятия.
- Выбор ученика (`localStorage["sched.prefs"]` = `{lang, classId, groups:{subjectId: groupId | [groupIds] | "__none"}}`) ссылается на **id**. Переименовывать можно, но менять или удалять id нельзя: у учеников сбросится выбор.
- Учебные дни: воскресенье–четверг. Пятница и суббота пропускаются (`schoolDay`, `stepDay`).

## Правила работы

1. **Не читать `index.html` целиком.** Строка 311 весит ~120 КБ. Ищи через Grep, читай куски через `offset/limit`, а данные разбирай скриптом (Python/Node: найти `id="app-state">` и распарсить JSON).
2. **Без сборки и зависимостей.** Не добавлять npm, бандлеры, фреймворки, внешние скрипты. Стиль кода — как вокруг: ES5, `var`, короткие функции, HTML через конкатенацию строк.
3. **Всё, что попадает в HTML, — через `esc()`.**
4. **Любой новый текст интерфейса — сразу на трёх языках** (`T.he`, `T.en`, `T.ru`). Проверять вёрстку и в RTL (иврит), и в LTR.
5. **Только сервер.** Вход и публикация идут только через Cloudflare Worker (`/login`, `/data`). Не возвращать проверку кода в браузере и публикацию без сервера. `config.js` и манифест должны оставаться в `<head>`.
6. **Данные расписания правятся осторожно.** На сайте живые данные берутся с сервера, поэтому правка встроенного `app-state` сама по себе их не меняет. Перед массовой правкой данных уточни у пользователя. Новые id не должны совпадать с существующими. Ссылки (`subjectId`, `aud.id`, `lessonId`) должны указывать на существующие записи.
7. **Палитра p2 перекрывает базовые стили.** Если стиль «не применяется», ищи правило `html[data-look="p2"] …` или `html[data-look^="p"] …` ниже в CSS.
8. **Не трогать без запроса:** адрес API в `config.js`, токен Cloudflare Analytics, хеши кода редактора, логику 409-конфликта при публикации.
9. **Мобильные первым делом:** крупные кнопки (≥44px), `env(safe-area-inset-*)`, тёмная тема.
10. Коммиты маленькие и с понятным описанием. Пуш в ветку по умолчанию = публикация для всех учеников.

## Проверка

Тестов нет. После каждого `Edit`/`Write` автоматически срабатывает хук `.claude/hooks/check-code.mjs`:
- `index.html` — синтаксис JS в `app-js` (с номером строки), JSON в `app-state`, целостность данных (уникальные id, существующие предметы/группы/классы/уроки, день 0–4, номер урока есть в `periods`, тип и дата изменения), наличие `config.js` и манифеста в `<head>`;
- `*.js` — синтаксис (`.mjs` — как модуль, через `node --check`, без запуска); `*.json`, `*.webmanifest` — корректный JSON.

Если хук нашёл ошибку, исправь её до продолжения работы. Ручной запуск: `node .claude/hooks/check-code.mjs index.html`.

Посмотреть приложение вживую: `python3 -m http.server 8000` в корне и открыть `http://localhost:8000` (с сервера подтянутся живые данные).
